01 / Method

Separate the action
from what gets stored.

The frozen recurrent model proposes a short control sequence. A bounded local solve improves it. Paired simulator branches execute the identical first action, then independently retain or discard the corrected state and plan.

A frozen proposal

The model updates its 256-dimensional persistent state from the current observation, then decodes 12 navigation actions or eight joint-velocity vectors.

zt0 = f(zt−1, xt)
Ut0 = g(zt0; ct)

A bounded correction

Damped Gauss–Newton updates the state. Candidates must decrease the fixed local objective and stay within cumulative state and action-change limits.

v = −(JTJ + λI)−1JTR
At most 3 candidate trials per input

A memory intervention

Retain and discard have the same corrected action at the intervention. Only the state passed to the next recurrence changes. Both still receive the executed action as an input.

Retain: store corrected z
Discard: store proposal z0

The matched cache experiment resumes a shared action-space solver, with no further state correction. State retention adds a conditional 0.7% [0.2, 1.2] navigation cost reduction and 1.1% [0.3, 1.9] in chain control beyond plan caching. Paper, Section 5.2 and Table 1 ↗

02 / Results

Remembering helps.
Planning remains a strong baseline.

Retention improves the repeated controller even though action-space search reduces the immediate objective more. Fitting an action-space solution into memory recovers most of the benefit. MPC achieves similar success with fewer contacts.

The direct effect is brief

On common-input replay, retaining a correction lowers next-proposal loss by 3.2% in navigation and 4.4% in chain control. The effect declines over the next few inputs and is close to zero by eight.

Success and contacts tell different stories

Retained state reaches 85.4% navigation success with 14.2 contact-containing steps per 1,000. MPC reaches 85.8% with 6.0. The predictive filter lowers contacts further, to 4.1, but takes longer to reach goals.

Configurations were selected under 4 ms mean and 8 ms p99 latency targets on one CPU/GPU workstation. The reported p99 is a measured quantile. Paper, Sections 4.2 and 5.1 ↗

03 / Context

A useful correction
can become old advice.

Change the target or delay the sensor records and the average retention benefit disappears. A simple rollback rule saves the uncorrected state for one input and withholds the latest correction when the context changes.

Measured one-shot intervention from Table 4. Further optimization is disabled; this is separate from the full-episode rollback test.

Undo the latest update

The rollback switch checks the active target identifier and sensor timestamp before the next recurrence. If the target changes or the record is more than one input old, it uses the saved proposal state.

ẑ = z0 + a (z̃ − z0)
a = 0 for changed target or stale record

During intermittent sensing delays, rollback raises navigation success from 82.1% to 83.4%, and chain success from 71.8% to 73.0%, compared with always retaining. It removes the latest correction, not older changes already carried through memory.

04 / Scope

A local adjustment,
with a local timescale.

The evidence comes from one gated recurrent architecture in two simulators. Both tasks provide differentiable geometry and a target that can be scored before acting. The result concerns where a local solution is stored and how long it remains useful.

Does the title establish that attention is unnecessary?

No attention-based architecture comparison is made here. The paper tests retained state corrections in a frozen recurrent controller. The same-action intervention isolates the memory effect.

What does the descent test guarantee?

Accepted candidates decrease one fixed local objective and stay within the stated state ball. That does not guarantee physical constraint satisfaction. Stale observations can make the supplied objective misleading even when its loss decreases.

How much does retention add beyond caching a plan?

The conditional cost reductions are modest: 0.7% in navigation and 1.1% in chain control over eight inputs. They are positive in four of five navigation models and all five chain models. A plan cache explains part of the broader retention benefit.
